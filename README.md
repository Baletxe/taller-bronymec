# Fabricación Bronymec

App del taller (pedidos de CAF y Talgo, previsión y planificación de máquinas).

Todo lo que hay aquí va cifrado (AES-256-GCM, clave derivada con PBKDF2-SHA256 de 600.000 iteraciones y sal aleatoria). Sin la contraseña del taller no se puede leer. No contiene precios, importes ni contratos.
